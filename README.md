The **AI Career Guidance Assistant** is an AI-based application designed to help students explore suitable career options based on their skills, interests, and experience level.

### Key Features

* Skill-based career recommendations
* Interest-based career matching
* Career ranking
* Personalized career suggestions
* NLP-based chatbot interaction

```text

    ↓

    ↓

    ↓

    ↓
Career Guidance
```

## 💼 AI Internship Recommendation Engine

The **AI Internship Recommendation Engine** is a recommendation system designed to suggest suitable internships based on user preferences and available internship information.

The system combines **Collaborative Filtering** and **Content-Based Filtering** to provide relevant recommendations.

### Key Features

* Personalized internship recommendations
* Collaborative Filtering
* Content-Based Filtering
* Hybrid recommendation approach
* Preference-based matching
* Ranked internship suggestions

### Recommendation Workflow

```text
User Profile
    ↓
User Preferences
    ↓
Collaborative Filtering
        +
Content-Based Filtering
    ↓
Hybrid Recommendation
    ↓
Ranked Internships
```

## 📄 AI Resume Reviewer & ATS Optimizer

The **AI Resume Reviewer & ATS Optimizer** is an AI-powered application that analyzes resumes and provides feedback to improve resume quality and ATS compatibility.

The application supports **PDF, DOCX, and TXT** resume files and can also compare resumes with a provided job description.

### Key Features

* Resume parsing
* Text preprocessing
* Skill extraction
* Experience analysis
* Education analysis
* ATS compatibility checking
* Job description matching
* Resume scoring
* Personalized feedback

### Main Workflow

```text
Resume Upload
    ↓
Resume Parser
    ↓
Text Preprocessing
    ↓
Skill / Experience / Education Analysis
    ↓
ATS Checking
    ↓
Job Description Matching
    ↓
Scoring
    ↓
Feedback & Suggestions
```

### Technologies & Tools

`Python` · `NLTK` · `Scikit-learn` · `Pandas` · `NumPy` · `PyPDF` · `python-docx` · `Streamlit` · `Plotly`

## 💡 AI Project Topic Recommender

The **AI Project Topic Recommender** is an AI-based recommendation system that suggests suitable project topics according to a student's interests, skills, experience level, domain, and difficulty preference.

The system uses **NLP, TF-IDF, Cosine Similarity, and Content-Based Filtering** to generate and rank project recommendations.

### Key Features

* Interest-based recommendations
* Skill-based recommendations
* Domain filtering
* Difficulty filtering
* TF-IDF text representation
* Cosine similarity-based ranking
* Top project recommendations

### Recommendation Workflow

```text
Student Profile
    ↓
Interests & Skills
    ↓
Text Preprocessing
    ↓
TF-IDF Vectorization
    ↓
Cosine Similarity
    ↓
Content-Based Filtering
    ↓
Ranked Project Topics
```
